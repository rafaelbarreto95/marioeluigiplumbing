# 🍄 Mario & Luigi Plumbing Services

Landing page temática inspirada no universo Mario Bros para divulgação de serviços de encanamento.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* FormSubmit
* Deploy datails

## ✨ Funcionalidades

* Vídeo de fundo
* Design responsivo
* Formulário de contato
* Cards de serviços
* Animações CSS
* Tema inspirado em Mario Bros
